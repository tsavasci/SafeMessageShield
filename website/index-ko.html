어떻게 작동하나요?

3가지 간단한 단계로 시작하세요

1

앱 다운로드

App Store에서 Safe Message Shield를 무료로 다운로드하세요.

2

확장 기능 활성화

iOS 설정에서 SMS 필터링 및 전화 차단을 활성화하세요.

3

번호 추가

수동으로 번호를 입력하거나 연락처에서 선택하세요.

개인정보 보호가 최우선

Safe Message Shield는 개인정보를 보호하도록 설계되었습니다. 메시지 내용, 전화번호, 개인정보는 기기를 벗어나지 않습니다.

  • ✓모든 데이터는 암호화되어 기기에 저장됩니다
  • ✓서버로 데이터를 전송하지 않습니다
  • ✓인터넷 연결 불필요
  • ✓광고나 추적 없음
  • ✓곧 오픈소스 제공
