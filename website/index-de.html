Leistungsstarke Funktionen

Entwickelt für Ihre Privatsphäre, entwickelt für Ihren Komfort

SMS-Filterung

Unerwünschte SMS-Nachrichten werden automatisch in den Ordner „Werbung" verschoben. Nie wieder gestört werden.

📞

Anrufblockierung

Wenn blockierte Nummern Sie anrufen, klingelt Ihr Telefon nicht. Stillschweigend abgelehnt.

🔒

Totale Privatsphäre

Alle Ihre Daten bleiben auf Ihrem Gerät. Keine Daten an Server gesendet, funktioniert vollständig offline.

Wie funktioniert es?

Beginnen Sie in 3 einfachen Schritten

1

App herunterladen

Laden Sie Safe Message Shield kostenlos aus dem App Store herunter und öffnen Sie es.

2

Erweiterungen aktivieren

Aktivieren Sie SMS-Filterung und Anrufblockierung in den iOS-Einstellungen.

3

Nummern hinzufügen

Geben Sie Nummern manuell ein oder wählen Sie sie aus Kontakten. Das war's!

Ihre Privatsphäre ist unsere Priorität

Safe Message Shield wurde von Grund auf entwickelt, um Ihre Privatsphäre zu schützen. Keine Nachrichteninhalte, Telefonnummern oder persönlichen Informationen verlassen Ihr Gerät.

  • ✓ Alle Daten werden verschlüsselt auf Ihrem Gerät gespeichert
  • ✓ Keine Daten an Server gesendet
  • ✓ Keine Internetverbindung erforderlich
  • ✓ Keine Werbung oder Tracking
  • ✓ Open-Source-Code demnächst
